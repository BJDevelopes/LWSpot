# LWSpot documentation

Everything about using LWSpot, the lightweight Spotify client for Windows.
These pages read the same here on GitHub and on the
[documentation site](https://bjdevelopes.github.io/LWSpot/), which is built
from this folder.

Start here if you are new to LWSpot.

| Page | What it covers |
|---|---|

| [Download](_guide/download.md) | Download LWSpot for Windows and install it, or use the portable copy. |
| [Getting started](_guide/getting-started.md) | Sign in through your browser and enable playback on this computer. |
| [Everyday use](_guide/using-lwspot.md) | Play music, arrange playlists, find lyrics, and make LWSpot your own. |
| [The Winamp mini player](_guide/winamp.md) | Classic Winamp 2 skins with an analyser, equalizer, and playlist. |

| [Make it even faster](_guide/make-it-even-faster.md) | Scrolling performance, and fewer loading delays with your own Spotify app. |
